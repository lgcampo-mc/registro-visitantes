# Taller 01 - Registro de Visitantes
Proyecto desarrollado en Spring Boot (Java 21) para practicar conceptos de instancias, métodos `static` y beans de Spring.

## Cómo ejecutar:
1. Abrir el proyecto en IntelliJ IDEA.
2. Esperar a que Maven descargue las dependencias[cite: 1].
3. Ejecutar la clase principal `RegistroVisitantesApplication.java`.
4. La API estará disponible en el puerto `http://localhost:8080/api/visitantes`.
